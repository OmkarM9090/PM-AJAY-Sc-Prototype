# SKILLS — Agent Skill Map

Use the detailed `SKILL.md` files under `.agents/skills/`.

### Required skills
- `voice-agent`: real phone-call flow, browser voice fallback, ASR/TTS states, provider adapter.
- `multilingual`: Marathi/Hindi/English translations, language persistence, code-mixed UX.
- `recommendation`: profile-driven retrieval, hard filters, semantic/lexical ranking, explainability, roadmap.
- `qa`: end-to-end functional, responsive, accessibility and demo regression testing.

### Skill usage rule
Read the relevant skill before implementing that area. Keep skills reusable and do not embed provider secrets or hardcoded policy claims inside them.
