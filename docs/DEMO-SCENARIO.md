# Judge Demo Scenario

## Persona
- Education: 10th
- Skills: Farming, Pump Repair
- Goal: Self-employment
- Mobility: Limited
- Location: Demo village/pincode

## Demo script
1. Open judge dashboard.
2. Dial the configured demo phone number (or use the web voice simulator if telephony is not configured on the demo machine).
3. Choose Marathi/Hindi/English.
4. Hear consent.
5. Answer naturally.
6. Watch transcript appear on dashboard.
7. Show extracted profile.
8. Confirm.
9. Show informal skills.
10. Show NSQF/RPL mapping.
11. Show skill gaps.
12. Compare training, job and self-employment options.
13. Open “Why this?”
14. Open roadmap.
15. Demonstrate changing goal to wage employment and show recommendation re-ranking.
16. Save/download/share roadmap.

## Judge talking points
- Existing platforms already provide much of the ecosystem.
- Livelihood Mitra focuses on the decision layer that starts from the beneficiary's story and constraints.
- The LLM handles conversation; trusted data and deterministic logic handle policy/eligibility decisions.
