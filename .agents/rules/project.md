# Project Rules

- Never create a generic chatbot.
- Never claim official government approval.
- Never hardcode unsupported policy numbers.
- Treat SIA, SIDH, NCS and PM-AJAY as existing ecosystem components.
- Real calling is a core capability; web is the visual/judge interface.
- Marathi, Hindi and English are mandatory for the first release.
- Use provider adapters and local fallbacks.
- Keep mock data clearly labelled.
