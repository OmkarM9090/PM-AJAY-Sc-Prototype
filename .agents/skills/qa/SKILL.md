# QA Skill

## Required passes
### Functional
Routes, buttons, persistence, voice/demo mode, language switching, recommendation changes, roadmap, save/share.

### Voice
Mic permission, silence, retry, low-confidence transcript, provider failure, browser unsupported state.

### Multilingual
Marathi/Hindi/English across the complete beneficiary journey.

### Responsive
Desktop, tablet, mobile; no overflow, clipping or overlap.

### Accessibility
Keyboard focus, labels, contrast, large touch targets, semantic controls.

### Security
No frontend secrets, no raw stack traces, admin separation, safe content rendering.

### Data integrity
Mock vs official sources clearly separated; no invented government claims.

## Exit condition
Do not declare complete until all critical scenarios pass and there are no console errors or broken navigation paths.
